Coin Toss Simulator
Author: MRayyanG
About
A simple Python project that simulates coin tosses based on the number of flips specified by the user. It counts the total number of heads and tails and explores randomness through repeated coin flips.
Inspired by an idea discussed in a video by Neil deGrasse Tyson, this project is a learning exercise in Python programming and probability.
Features
- Simulate a user-defined number of coin tosses.
- Generate random heads and tails.
- Count and display the total heads and tails.
- Repeat simulations until the user chooses to exit.
Technologies Used
- Python
- random module
Future Plans
- Add a graphical user interface (GUI).
- Save simulation results to a file.
- Explore patterns and streaks across multiple simulations.
Running the Project
1. Install Python 3.
2. Download or clone this repository.
3. Run the Python script from your terminal.
